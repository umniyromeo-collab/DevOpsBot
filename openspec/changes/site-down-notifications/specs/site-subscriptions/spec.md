# Spec Delta

## Purpose

Приём от пользователя Telegram списка сайтов, о которых он хочет получать уведомления, и постоянное
хранение этого списка.

## ADDED Requirements

### Requirement: Задание списка подписок
Система SHALL принимать команду `/subscribe <url> [<url> ...]` и делать переданные сайты полным списком подписок пользователя, заменяя предыдущий. В ответ бот MUST прислать итоговый список подписок.

#### Scenario: Первая подписка
- **WHEN** пользователь без подписок отправляет `/subscribe` с двумя сайтами из списка
- **THEN** пользователь подписан на эти два сайта, и бот присылает их в ответ

#### Scenario: Замена списка
- **WHEN** пользователь, подписанный на сайты A и B, отправляет `/subscribe` с сайтом C
- **THEN** пользователь подписан только на сайт C

### Requirement: Снятие всех подписок
Система SHALL считать команду `/subscribe` без адресов снятием всех подписок пользователя и подтверждать это ответом.

#### Scenario: Команда без адресов
- **WHEN** пользователь с подписками отправляет `/subscribe` без адресов
- **THEN** у пользователя не остаётся подписок, и бот сообщает об этом

### Requirement: Подписка только на сайты из списка
Система MUST принимать подписку только на сайты из фиксированного списка. Адреса не из списка SHALL быть отклонены и перечислены в ответе, а адреса из списка SHALL быть сохранены.

#### Scenario: Часть адресов неизвестна
- **WHEN** пользователь отправляет `/subscribe` с сайтом из списка и сайтом не из списка
- **THEN** подписка оформлена только на сайт из списка, а бот называет отклонённый адрес

#### Scenario: Все адреса неизвестны
- **WHEN** ни один адрес из команды не входит в фиксированный список
- **THEN** подписки пользователя не меняются, а бот называет отклонённые адреса

### Requirement: Подписки переживают перезапуск
Система SHALL хранить подписки постоянно, чтобы после перезапуска бота уведомления приходили без повторной подписки.

#### Scenario: Бот перезапущен
- **WHEN** пользователь подписан на сайт и бот перезапускается
- **THEN** подписка сохраняется, и пользователь получает уведомления по этому сайту

### Requirement: Подсказка на прочие сообщения
Система SHALL отвечать на любое другое текстовое сообщение подсказкой о формате команды и MUST NOT менять при этом подписки.

#### Scenario: Произвольный текст
- **WHEN** пользователь отправляет текст, не являющийся командой `/subscribe`
- **THEN** бот присылает подсказку, а подписки не меняются
